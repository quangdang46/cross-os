# Install CrossOS

1. Download the signed app (macOS .app / Windows MSI) and open it.
2. **Welcome** — CrossOS explains what it will do. Nothing is enabled yet.
3. **Enable per plugin** — turn on only what you want. Nothing auto-enables.
4. **Open System Settings** — CrossOS guides you to grant the access it
   needs (keyboard and accessibility on macOS; input on Windows).
5. **Verify ready** — the Activity page shows a green check when each part
   is working. New additions run a short trial first; confirm on the
   Safety page or they roll back by themselves.

Stuck? The Activity page shows what CrossOS did and why, in plain words.
